# Lector de libros / Book reader

A Kino plugin that reads DRM-free `.mobi` and `.epub` books inside Kino.

- Search archive.org and browse a few Project Gutenberg classics.
- Covers, text size (−/+), a page slider and a bookmark that remembers your page.
- Big files download in pieces and resume on their own.

Hosts: `www.gutenberg.org`, `archive.org` and `*.archive.org`. Nothing else is contacted.

Plugin API 19 (Kino 0.9.81 or later).
